# Domain docs

This is a single-context repository.

Before working in an area, read the root `CONTEXT.md` and ADRs in `docs/adr/`
that apply to that area when those files exist. Proceed with repository
evidence when they do not.

Use terms defined in `CONTEXT.md` for issue titles, proposed designs, tests,
and implementation names. Surface any conflict with an applicable ADR rather
than silently contradicting it.
